Данные сохраняются в браузере на этом устройстве. Перед восстановлением копии текущие данные автоматически сохраняются в отдельный JSON-файл. Регулярно скачивай резервную копию и храни её отдельно. Учитываем легендарных героев; для Первозданных — также мифических. Процент не учитывает временные x2-бонусы.

Общая статистика

По типам осколков
Статистика результатов считает каждую сохранённую запись с героем. Если в одной серии выпало несколько героев, создай отдельную запись для каждого героя; так ни один результат не потеряется в статистике. Число открытых осколков при этом указывай только один раз, чтобы не задвоить счётчик.

Добавить призывы

Укажи результат серии. Для точного учёта при нескольких открытиях за раз лучше добавлять отдельные записи по мере выпадения легендарного героя.

История действий

Резервная копия включает счётчики и историю. Храни её вне браузера.
Формулы используют базовые шансы без временных x2-событий: Древние/Тёмные — 0,5% и +5 п.п. после 200 призывов без легендарного; Сакральные — 6% и +2 п.п. после 12; Первозданные — легендарный 1% и +1 п.п. после 75, мифический 0,5% и +10 п.п. после 200. Прирост прибавляется к шансу напрямую и ограничивается 100%. Пороги Первозданных основаны на актуальном стороннем справочнике, так как официальная таблица Plarium не публикует их отдельно. Прототип не связан с игровым аккаунтом и не считывает данные из игры автоматически. Иконки стилизованные.
