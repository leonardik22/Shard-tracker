SHARD TRACKER 1.0 — пакет для GitHub Pages / Android PWA

Содержимое:
- index.html — приложение и расширенная статистика;
- manifest.json — параметры установки PWA;
- service-worker.js — офлайн-кэш, обновлён до версии 1.0;
- icons/icon-192.png и icons/icon-512.png — значки приложения.

ЧТО НОВОГО В 1.0
- Общий обзор: всего открыто осколков, записанные легендарные/мифические результаты, число записей истории.
- Разбивка по каждому типу осколков: число открытий, счётчики Mercy, записанные результаты и среднее число открытий на один записанный результат.
- Сравнение фактической частоты легендарных результатов с базовым шансом.
- Для Первозданных дополнительно отображается фактическая частота мифических результатов и сравнение с базовым шансом.
- Показывается разница с базовым шансом в процентных пунктах.

ВАЖНО ПРО СТАТИСТИКУ
Фактическая частота считается как количество записанных результатов соответствующей редкости, делённое на общее число открытых осколков этого типа. Она зависит от полноты и способа ведения журнала и не предсказывает будущие призывы. Базовый шанс указан без Mercy и временных x2-бонусов. Среднее число открытий на записанный результат — справочный показатель по журналу, не точная оценка шанса выпадения.

Текущий формат записи не поддерживает несколько героев одной редкости в одной серии как отдельные результаты без повторного учёта количества осколков. Если в серии выпало несколько героев, статистика может быть неточной. Это ограничение формата записи, не нужно добавлять дублирующие серии только ради учёта нескольких героев.

ОБНОВЛЕНИЕ С ANDROID
1. В установленном приложении открой «Скачать резервную копию» и сохрани JSON в загрузки телефона.
2. Скачай этот ZIP и распакуй его на телефоне.
3. Открой свой репозиторий GitHub → shard-tracker. Замени файлы index.html, manifest.json, service-worker.js и папку icons содержимым из распакованной папки shard_tracker_pwa_1_0. Загружай сами файлы/папку icons, а не ZIP целиком.
4. Нажми Commit changes и дождись публикации GitHub Pages.
5. Открой сайт по прежнему адресу при подключённом интернете. Закрой установленное приложение полностью, затем открой снова. Если версия не обновилась сразу, подожди минуту и повтори запуск онлайн.

СОХРАННОСТЬ ДАННЫХ
- Ключ localStorage shardTrackerState сохранён, поэтому при обновлении на том же адресе данные должны остаться на месте.
- Всё равно сделай JSON-резервную копию до обновления.
- Не очищай данные браузера и не нажимай «Сбросить всё» при обновлении.
- Это PWA-пакет, не APK. Переустанавливать приложение обычно не нужно; после успешного обновления оно продолжит работать офлайн.
