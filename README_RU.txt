SHARD TRACKER 0.8 — PWA-пакет

В комплекте:
- index.html — приложение с сохранением локальных данных, статистикой, историей и резервными копиями;
- manifest.json — имя, значок и параметры установки;
- service-worker.js — кэширование для работы офлайн после первого открытия;
- icons/ — иконки 192×192 и 512×512.

ВАЖНО: браузеры Android не устанавливают PWA напрямую из ZIP или file://. Для установки нужен HTTPS-адрес.

Как использовать с телефона:
1. Распакуйте ZIP в папку.
2. Загрузите СОДЕРЖИМОЕ папки на статический хостинг, который выдаёт HTTPS и сохраняет структуру файлов. В корне сайта должны находиться index.html, manifest.json, service-worker.js и папка icons.
3. Откройте полученный HTTPS-адрес в Chrome на Android.
4. Дайте странице полностью загрузиться один раз, затем выберите меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».
5. Откройте установленное приложение онлайн хотя бы один раз; затем основные файлы будут доступны офлайн.

ДАННЫЕ:
- Счётчики и история хранятся локально в браузере/веб-приложении.
- Перед переходом с предыдущего прототипа скачайте JSON-резервную копию в версии 0.7.
- После открытия версии 0.8 восстановите эту копию через кнопку «Восстановить копию».
- Не очищайте данные старого браузера, пока не убедитесь, что импорт в 0.8 прошёл успешно.
- Резервные копии по-прежнему нужно хранить отдельно. Установка PWA сама по себе не синхронизирует данные между устройствами.

Это PWA-пакет для размещения, а не APK. В текущем окружении сайт не опубликован автоматически.
