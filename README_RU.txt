SHARD TRACKER 1.1 — пакет для Android / GitHub Pages

В комплекте:
- index.html — приложение с поддержкой нескольких героев в одной серии;
- manifest.json — параметры установки PWA;
- service-worker.js — офлайн-кэш версии 1.1;
- icons/ — иконки приложения.

ЧТО НОВОГО
1. В поле «Количество открытых осколков в серии» указывается общее количество.
2. В поле «Позиции легендарных героев» перечисляются все номера осколков, на которых выпали легендарные герои, например 2, 8, 10.
3. Для Первозданных отдельно указываются позиции мифических героев.
4. Один номер нельзя использовать для двух героев: один осколок даёт один результат.
5. Каждый герой считается отдельным результатом в статистике, а количество осколков серии добавляется только один раз.
6. Mercy-счётчик для каждой редкости сбрасывается по последнему соответствующему выпадению внутри серии.
7. Старые записи версии 1.0 продолжают читаться; резервные копии старого формата можно импортировать.

ОБНОВЛЕНИЕ С ANDROID
1. До обновления открой установленное приложение и нажми «Скачать резервную копию». Проверь, что JSON-файл появился в загрузках.
2. Скачай и распакуй ZIP.
3. Открой репозиторий GitHub `shard-tracker`. Замени файлы `index.html`, `manifest.json`, `service-worker.js` и папку `icons` содержимым комплекта. Не загружай ZIP как один файл.
4. Нажми Commit changes и дождись публикации GitHub Pages.
5. Открой сайт по прежнему адресу при подключённом интернете, затем полностью закрой установленное приложение и открой снова. При необходимости повтори запуск онлайн через некоторое время, чтобы обновился service worker.
6. Проверь счётчики, Mercy, историю и импорт/экспорт. После получения новой версии приложение снова будет работать офлайн.

ВАЖНО
- Ключ localStorage `shardTrackerState` сохранён, чтобы данные остались на прежнем сайте.
- Не очищай данные браузера и не нажимай «Сбросить всё» при обновлении.
- Это PWA, а не APK. Устанавливать приложение заново обычно не нужно.
- JSON-резервную копию храни отдельно и не публикуй в GitHub.
- Результаты вводятся вручную. Частота выпадений зависит от полноты журнала и не предсказывает будущие призывы.
